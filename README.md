# Простейшее веб-приложение на Flask

**Минималистичный шаблон веб-приложения** на базе микрофреймворка Flask, демонстрирующий базовую структуру проекта, работу с HTML-шаблонами (`Jinja2`) и подключение статических файлов стилей (CSS) и изображений.

## Структура проекта

```text
flask_app/
├── app.py            # Основной скрипт инициализации и запуска сервера
├── templates/
│   └── index.html    # HTML-шаблон главной страницы сайта
└── static/
    ├── style.css     # Файл со стилями элементов (CSS)
    └── logo.png      # Статическое изображение/логотип
```

## Инструкция по запуску

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение. Создайте и активируйте его:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Установите фреймворк Flask с помощью пакетного менеджера `pip`:
```bash
pip install flask
```

### 3. Добавление ресурсов
Убедитесь, что в папку `static/` добавлено изображение с именем `logo.png`. Если изображение имеет другое расширение (например, `.jpg`), обновите строку подключения в файле `templates/index.html`.

### 4. Запуск сервера
Запустите главный файл приложения:
```bash
python app.py
```

После запуска в консоли появится техническое предупреждение `WARNING: This is a development server...`. Это нормальное поведение для встроенного сервера разработки.

### 5. Просмотр сайта
Откройте любой веб-браузер и перейдите по адресу:
```text
http://127.0.0.1:5000/
```

## Реализованный функционал
* **`app.py`** — настроен роутинг для главной страницы (`/`) и включен отладочный режим `debug=True` для автоматического применения изменений кода без перезапуска сервера.
* **`index.html`** — базовая верстка страницы с использованием динамических путей `url_for` для корректного подключения файлов из папки `static/`.
* **`style.css`** — кастомные стили для центрирования контента, изменения шрифтов заголовков и адаптивности изображения.
